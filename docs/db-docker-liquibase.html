Configuração: SQL Server (Docker) + Liquibase

Validado: container healthy, database matriculas_db criado, 5 changeSets Liquibase aplicados.

Stack completa (Compose)

./bin/stack-up.sh
# sobe SQL Server + backend Spring Boot + frontend Angular/nginx
  • Frontend: http://localhost:4200 (proxy /api ? backend)
  • Backend: http://localhost:8080
  • Swagger: http://localhost:8080/swagger-ui/index.html

Subir so o banco

cp .env.example .env   # se ainda nao existir
./bin/db-up.sh         # sobe SQL Server + cria matriculas_db
  • Host/porta: localhost:1433
  • Database: matriculas_db
  • Usuario: sa / senha em .env (padrao Matriculas@2026)
  • Container: matriculas-sqlserver

Spring Boot (profile docker)

cd backend
export JAVA_HOME=../.tools/jdk-21   # se usar o JDK local do projeto
mvn spring-boot:run -Dspring-boot.run.profiles=docker

O Liquibase roda no startup a partir de db/changelog/db.changelog-master.xml.

Arquivos principais

  • docker-compose.yml ? SQL Server 2022 + job de init do database
  • docker/sqlserver/init/01-create-database.sql ? cria matriculas_db
  • backend/src/main/resources/application-docker.yml ? JDBC MSSQL
  • backend/src/main/resources/db/changelog/changes/001-create-schema.xml ? tabelas do dominio

Schema criado pelo Liquibase

aluno, curso, disciplina, turma, matricula (+ constraints de status, vagas e unique aluno+turma).
